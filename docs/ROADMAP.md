# Roadmap

| Stage | Content | Status |
|---|---|---|
| 0 | Backend: tables with `tenant_id`, roles, GraphQL, demo data, tests | ✅ done |
| 1 | Web UI: dashboard, plan (table + board), calendar, library, projects, assistant, team, 4 locales | ✅ done |
| 1b | Access for team members without the site-admin role | ✅ done |
| 2 | **AI core**: draft / rewrite / adapt to a channel / titles / hashtags through the platform AI gateway; bring-your-own-key and platform-model modes; per-project brand memory (project card); run log (gateway journal) and daily limits | ✅ done |
| 2b | «Golden samples» in the brand memory, per-tariff generation limits | planned |
| 3 | **Factory**: ideas, plan for a period, batch adaptation by queue, approval with comments, an «AI factory» page | planned |
| 4 | **Community build**: this configuration as an installable layer of the free self-hosted edition; release, tariffs, demo | planned |
| 5 | **Publishing** through the messenger core (Telegram / Max / VK), image generation, reach metrics | planned |

Deliberately out of scope for v1: publishing through channel APIs (stage 5), PDF / Excel reports, per-project permissions, custom models (only the platform gateway), indexable public content pages.
